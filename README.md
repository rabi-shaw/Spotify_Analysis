# Spotify_Analysis

# 🎵 Spotify Music Streaming Analytics Dashboard

An interactive Power BI dashboard designed to analyze Spotify listening
behavior, streaming performance, artist and album popularity, track
performance, release trends, and time-based listening patterns.

---

## 📊 Project Overview

This project transforms Spotify listening data into an interactive
analytical dashboard using Microsoft Power BI.

The dashboard provides a complete view of music consumption patterns
across artists, albums, tracks, release years, dates, weekdays, months,
and hours.

---

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze overall Spotify streaming performance
- Identify top artists, albums and tracks
- Understand listening behavior over time
- Identify peak listening periods
- Analyze new vs. old song consumption
- Analyze release-year performance
- Measure monthly and daily growth
- Analyze song completion and skipping behavior
- Create time-intelligence metrics
- Build an interactive executive-level dashboard
